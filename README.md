## tomx

A Rails inspired prototype exploring MVC concepts in a modern TypeScript stack.

This project is an experiment to see how ideas from Rails can be applied using
tools like Hono, Drizzle, Zod and JSX templates. Drizzle has become a more
mature option for working with TypeScript databases, Zod provides schema
validation and Hono JSX support makes it possible to build server rendered
templates without adding a separate frontend framework.

The project is a full CRUD application built to explore conventions, structure
and developer experience. It is not intended to be a production framework, but
rather a playground for experimenting with these ideas.
